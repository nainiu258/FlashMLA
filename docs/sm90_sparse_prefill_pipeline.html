SM90 Sparse Prefill：三 Warpgroup 流水

每个 CTA 有 3 个 warpgroup：WG0、WG1 计算 attention；WG2 依据 indices 异步 gather 两个 64-token 的 KV block。图中展示一对 block（KV0/KV1）以及下一对 block 的预取如何与当前计算重叠。

WG0：P0 / O 左半 WG1：P1 / O 右半 WG2：稀疏 gather producer ready / free barrier

Producer 做什么？

  1. 读取 64 个 token 的稀疏 index。
  2. 检测 -1、越界与 topk_length 尾部。
  3. 将 KV 分段异步放入两个 shared-memory buffer。

消费者何时开始？

  1. 只等待自己当前所需半段的 ready。
  2. QK、online softmax 和 PV 交错执行。
  3. 用完的半段立即发送 free。

为什么适合 sparse？

  1. 随机 token 地址由 producer 隔离。
  2. consumer 始终面对规整的 SMEM tile。
  3. 随机访问延迟被 Tensor Core 计算掩盖。

对应源码：csrc/sm90/prefill/sparse/phase1.cuh 中 producer 位于约 463–557 行；消费者的 ready/free 使用位于约 259–438 行。
